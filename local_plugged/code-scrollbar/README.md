# code-scrollbar

Local plugin hiển thị scrollbar kiểu VS Code ở cạnh phải cửa sổ code.

- cột trái: vị trí error và warning trong toàn bộ file;
- cột phải: vùng đang xem và dòng hiện tại;
- góc trên bên phải: số error/warning hoặc dấu tick xanh khi file sạch;
- lấy diagnostics từ CoC, fallback sang `vim.diagnostic`;
- `<leader>sb` hoặc `:CodeScrollbarToggle` để bật/tắt.

Mọi nội dung xuất hiện trên giao diện đều dùng tiếng Anh.
