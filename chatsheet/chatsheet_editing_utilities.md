# Tiện ích soạn thảo

## Minimap và highlight symbol

| Chế độ | Phím/lệnh | Tác dụng |
|---|---|---|
| Normal | `<leader>mm` | Bật/tắt minimap (`mini.map`) |
| Command | `:IlluminateToggle` | Bật/tắt Illuminate |
| Command | `:IlluminatePause` | Tạm dừng Illuminate |
| Command | `:IlluminateResume` | Tiếp tục Illuminate |
| Command | `:IlluminateToggleBuf` | Bật/tắt Illuminate cho buffer hiện tại |
| Command | `:IlluminatePauseBuf` | Tạm dừng Illuminate cho buffer hiện tại |
| Command | `:IlluminateResumeBuf` | Tiếp tục Illuminate cho buffer hiện tại |

Minimap tự động ẩn với buffer quá ngắn, buffer đặc biệt, `nerdtree`, `gitcommit`, `startuptime`.

## Auto-pairs, auto-save và fold

| Lệnh/chức năng | Tác dụng |
|---|---|
| `auto-pairs` | Tự động chèn cặp ngoặc/dấu nháy trong Insert mode |
| `vim-auto-save` | Đang bật sẵn: `g:auto_save = 1`, chế độ im lặng |
| `:AutoSaveToggle` | Bật/tắt tự động lưu |
| `SimpylFold` | Hỗ trợ fold cho Python |
| `:SimpylFoldDocstrings` | Bật/tắt fold docstring của Python |
| `:SimpylFoldImports` | Bật/tắt fold import của Python |
| `zc` | Đóng fold, phím mặc định của Vim |
| `zo` | Mở fold, phím mặc định của Vim |
| `za` | Bật/tắt fold, phím mặc định của Vim |
