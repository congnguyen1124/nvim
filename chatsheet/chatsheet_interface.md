# Theme, statusline và giao diện

| Lệnh | Tác dụng |
|---|---|
| `:colorscheme onedark` | Theme đang dùng |
| `:colorscheme nightsky` | Đổi sang nightsky nếu muốn |
| `:TransparentToggle` | Bật/tắt nền trong suốt |
| `:TransparentEnable` | Bật nền trong suốt |
| `:TransparentDisable` | Tắt nền trong suốt |
| `:AirlineTheme <theme>` | Đổi theme Airline |
| `:AirlineRefresh` | Làm mới Airline |
| `:AirlineToggle` | Bật/tắt Airline |
| `:AirlineToggleWhitespace` | Bật/tắt extension whitespace |
| `:AirlineExtensions` | Xem các extension Airline |

Airline hiện dùng theme `onedark`, có tabline, tên tab hiển thị theo tên file.
