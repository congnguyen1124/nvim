# Dart và Flutter

`flutter-tools.nvim` được thiết lập trong `init.lua`, nhưng plugin này chỉ tạo các command sau khi bạn mở file `*.dart` hoặc `pubspec.yaml`.

| Lệnh | Tác dụng |
|---|---|
| `:FlutterRun` | Chạy project Flutter |
| `:FlutterDebug` | Chạy ở chế độ debug |
| `:FlutterVisualDebug` | Bật/tắt visual debug |
| `:FlutterDevices` | Chọn thiết bị |
| `:FlutterEmulators` | Chọn emulator |
| `:FlutterReload` | Hot reload |
| `:FlutterRestart` | Khởi động lại ứng dụng |
| `:FlutterQuit` | Dừng session |
| `:FlutterAttach` | Kết nối vào ứng dụng đang chạy |
| `:FlutterDetach` | Ngắt kết nối nhưng giữ ứng dụng chạy |
| `:FlutterOutlineToggle` | Bật/tắt Flutter outline |
| `:FlutterOutlineOpen` | Mở Flutter outline |
| `:FlutterDevTools` | Chạy Dart DevTools |
| `:FlutterDevToolsActivate` | Kích hoạt DevTools |
| `:FlutterOpenDevTools` | Mở DevTools |
| `:FlutterCopyProfilerUrl` | Sao chép URL của profiler |
| `:FlutterPubGet` | Chạy `flutter pub get` |
| `:FlutterPubUpgrade` | Chạy `flutter pub upgrade` |
| `:FlutterLspRestart` | Khởi động lại Dart LSP |
| `:FlutterSuper` | Đi tới superclass/method |
| `:FlutterReanalyze` | Yêu cầu Dart LSP phân tích lại |
| `:FlutterRename` | Đổi tên và cập nhật imports |
| `:FlutterLogToggle` | Bật/tắt buffer log |
| `:FlutterLogClear` | Xóa buffer log |
